/ FAQ

      
Często zadawane pytania

      

        Czy narzędzie wysyła mój JSON na serwer?
        
Nie. Cały JSON Formatter działa w czystym JavaScript w Twojej przeglądarce — formatowanie, walidacja, konwersja, JSONPath i diff. Twoje dane nigdy nie są nigdzie wysyłane, nie ma backendu ani telemetrii.

      

      

        Jakie tryby oferuje JSON Formatter?
        
Cztery: Formatuj i drzewo (upiększanie, minifikacja, walidacja na żywo, widok drzewa z kopiowaniem ścieżek), Konwersja (JSON ↔ YAML oraz JSON ↔ CSV), JSONPath (odpytywanie danych) oraz Diff (porównanie dwóch JSON-ów).

      

      

        Jak działa walidacja i wykrywanie błędów?
        
Walidacja działa na żywo podczas pisania. Jeśli JSON jest nieprawidłowy, narzędzie pokazuje czytelny komunikat wraz z numerem linii i kolumny, w której wystąpił błąd, dzięki czemu szybko znajdziesz literówkę czy brakujący przecinek.

      

      

        Czym jest tryb konwersji JSON ↔ YAML / CSV?
        
Konwersja zamienia JSON na YAML i odwrotnie, a także tablicę obiektów JSON na CSV (z nagłówkami) i CSV z powrotem na JSON. CSV jest obsługiwany zgodnie z RFC 4180 — poprawnie traktujemy cudzysłowy, przecinki i znaki nowej linii w polach.
